## 300. 最长递增子序列 · Longest Increasing Subsequence

求数组中最长严格递增子序列的长度。子序列可以不连续，但必须保持原来的先后顺序。

**状态：** `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度。

```python
class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        n = len(nums)
        dp = [1] * n

        for i in range(n):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)

        return max(dp)
```

- 修改 `d[j]` 为 `dp[j]`。
- 每个元素自己就能组成长度为 1 的子序列，因此全部初始化为 1。
- 枚举前面的所有 `j`，只要 `nums[j] < nums[i]`，就可以接到以 `j` 结尾的序列后面。
- 最优序列不一定以最后一个元素结尾，所以返回 `max(dp)`。
- 时间 O(N²)，空间 O(N)。

## 152. 乘积最大子数组 · Maximum Product Subarray

求非空连续子数组的最大乘积。

**状态：** `dp1[i]`、`dp2[i]` 分别表示必须以 `nums[i]` 结尾的最大、最小乘积。

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        n = len(nums)
        dp1 = [0] * n
        dp2 = [0] * n

        dp1[0] = nums[0]
        dp2[0] = nums[0]

        for i in range(1, n):
            dp1[i] = max(
                dp1[i - 1] * nums[i],
                dp2[i - 1] * nums[i],
                nums[i]
            )
            dp2[i] = min(
                dp1[i - 1] * nums[i],
                dp2[i - 1] * nums[i],
                nums[i]
            )

        return max(dp1)
```

- 原状态转移正确：选择是“接前一段最大乘积”“接前一段最小乘积”或“从当前元素重新开始”。
- 负数会翻转大小关系，因此最大、最小乘积都需要保存。
- 原来的 `max(dp1, dp2)` 按列表的字典序比较，不是逐项比较。在这份正确递推下，它仍会选到 `dp1` 或与其相同的列表，所以不是必然错误；直接写 `max(dp1)` 更符合状态含义。
- 若以后压缩成两个变量，必须先保存上一轮的两个值，避免更新最大值后影响最小值计算。
- 时间 O(N)，空间 O(N)。

## 416. 分割等和子集 · 0-1 Knapsack（0-1 背包）

判断能否将正整数数组分成两个和相等的子集，每个元素只能使用一次。

总和为奇数时无法平分；否则转化为：能否选出一些元素，使其和恰好为总和的一半。

**状态：** 处理当前元素后，`dp[j]` 表示使用已处理元素能否凑出和 `j`。

```python
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        total = sum(nums)
        if total % 2 != 0:
            return False

        ta = total // 2
        dp = [False] * (ta + 1)
        dp[0] = True

        for num in nums:
            for j in range(ta, num - 1, -1):
                dp[j] = dp[j] or dp[j - num]

        return dp[ta]
```

- 修正 `true`、`false` 为 `True`、`False`，`d[j]` 改为 `dp[j]`。
- 原来的 `range(ta, ta - nums[i], -1)` 范围不对。应从 `ta` 遍历到当前数字 `num`，包含 `num`。
- `dp[j]` 表示不选当前数字；`dp[j - num]` 表示剩余部分能凑出，因此可以再选当前数字。
- 容量倒序遍历，保证读取的较小容量还是处理当前数字之前的状态，防止同一个元素被重复使用。
- 时间 O(N × ta)，空间 O(ta)。

# 动态规划（DP）今日核心心法总结

## 一、 初始化原则：看 `i` 代表什么
- **如果 `i` 是数组下标（如 152 乘积、300 子序列）**：必须手动填 `dp[0]`（甚至 `dp[1]`）。
- **如果 `i` 是容量/金额/长度（如 139 单词、322 零钱、416 分割）**：只需要填 `dp[0]`（Base Case，比如 0 块钱或空串），剩下的交给 `for` 循环。
- **求最大/最小**：数组初始化为 `-inf / inf`，取 `max/min`。
- **求能否凑出（布尔值）**：数组初始化为 `False`，`dp[0] = True`。

## 二、 循环层数：看状态依赖谁
### 🟢 1. 单循环 = 线性 DP（只和“相邻”有关）

**特征**：当前状态 `dp[i]` 只依赖固定的前几个状态（`dp[i-1]` 或 `dp[i-2]`）。

**直观感受**：就像走楼梯，你只能一步一步往前迈。走到第 `i` 步时，你只需要看前一步或前两步的情况。

**代表题**：
* 70 爬楼梯（看前两步）
* 198 打家劫舍（看前两步）
* 53 最大子数组、152 乘积最大（看前一步）

### 🔵 2. 双循环 = 区间/背包 DP（要找“前面所有”或“特定目标”）

**特征**：当前状态 `dp[i]` 需要去前面所有状态里翻旧账（`j` 从 0 到 `i-1`），或者受制于一个特定的“目标值/容量”。

* **情况 A：跳着找前面（翻旧账）。**
  比如 300 最长递增子序列：`nums[i]` 可以接在前面任何一个比它小的数字后面，所以内层需要 `for j in range(i)` 遍历所有可能。

* **情况 B：特殊目标（凑数/容量）。**
  比如 322 零钱兑换、279 完全平方数、416 分割等和：你的目标是凑出金额 `amount` 或者填满容量 `target`。内层循环的 `for coin in coins` 或 `for j in range(...)`，就是在穷举当前状态下能做出的所有物品选择。

## 三、 max/min 里面装的是“选择”
- **300 题**：在所有的 `j` 中挑，选择是“接它”还是“不接”（`max(dp[i], dp[j] + 1)`）。
- **152 题**：遇到负数，最大变最小，最小变最大。选择是“自己单干”、“乘历史最大”、“乘历史最小”。必须维护两个 dp 数组（或两个变量）。

## 四、 背包问题绝杀：0-1 背包 vs 完全背包
- **完全背包（322 零钱、279 平方数）**：物品可无限次使用。内层循环**正序**遍历容量。
- **0-1 背包（416 分割等和）**：每个数字只能用一次。外层遍历物品，内层必须**倒序**遍历容量 `for j in range(ta, num - 1, -1)`，防止一个物品被重复使用。
